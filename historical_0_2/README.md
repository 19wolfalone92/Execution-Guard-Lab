# Execution Guard Lab 0.2.0 — независимая локальная лаборатория

26.11.2026. **PARTIAL**: реализованы и проверены 23 инструмента; ни один лабораторный инструмент не зарегистрирован и не вызван в обычном ChatGPT. Это отдельный проект, не патч Pro 0.6.0 и не средство выполнения ранее запрещенной операции. Никаких изменений GitHub, Production, настроек разрешений или существующего плагина.

## Воспроизведение

Python 3.13.5, jsonschema 4.26.0, pytest 9.0.2 — проверенная конфигурация. В отдельной папке и доверенной локальной среде:

```sh
python -m venv .venv
# активировать .venv согласно ОС
python -m pip install -r requirements.txt
python -m pytest -q --junitxml=tests.xml
python -B qualify.py > MCP_EVIDENCE.json
python -B lab.py
```

Последняя команда запускает сервер stdio: клиент отправляет UTF-8 JSON-RPC по одной строке. Отдельно можно запустить `python -B http_lab.py --port 8765`; HTTP слушает исключительно 127.0.0.1, путь `/mcp`, не является удаленным production-сервисом. GET на `/mcp` отвечает 405 (поток SSE не поддерживается); POST принимает JSON, клиент должен объявлять Accept `application/json, text/event-stream`. Версии handshake: 2025-03-26, 2025-06-18, 2025-11-25. Полная независимая проверка MCP SDK не выполнена: пакет `mcp` не установлен, поиск pip завершился `No matching distribution found for mcp`. Не заявлена поддержка версии 2026-07-28.

Пример запроса после initialize / notifications/initialized:
```json
{"jsonrpc":"2.0","id":3,"method":"tools/call","params":{"name":"math_calculate","arguments":{"operation":"divide","a":12,"b":4}}}
```
Ожидаемое structuredContent: `{"result":3.0}`.

## Структура

- `lab.py`: сохранены восемь исходных функций, централизованная валидация, JSON-RPC/stdio.
- `extensions.py`: пятнадцать новых ограниченных вычислительных функций.
- `http_lab.py`: отдельный локальный HTTP-процесс, не интернет-сервис.
- `test_lab.py`, `test_extended.py`, `test_http.py`: автоматизированные тесты.
- `qualify.py`: отдельный клиент, запускающий серверы повторно; журнал фактических запросов и ответов.
- `MCP_SCHEMAS.json`, `TOOL_REGISTRY.json`: входные и выходные схемы всех функций, метаданные, границы полномочий.
- `CANDIDATE_CATALOG.csv`: рассмотрение предложенных названий, объединение/отложенные функции.
- `TEST_RESULTS.txt`, `tests.xml`, `MCP_EVIDENCE.json`: результаты реальных испытаний, только синтетические данные.
- `ACCEPTANCE.json`: реестр приемки A–Q. `MANIFEST.sha256`: хеши содержимого.

## Архитектура и ограничения

Инструменты принимают только данные вызывающего. Нет внешних запросов, универсального HTTP-клиента, shell, произвольного исполнения кода, записи на диск из обработчиков, токенов, облачных БД, торговли, репозиторных операций. Анализ Python выполняет AST-разбор, а не выполнение кода. Анализ ZIP не извлекает файлы и не является антивирусной проверкой. Ограничения: JSON 128 KiB, глубина 20, числовые массивы до 256, Base64 до 64000 символов (48000 байт), ZIP до 128 элементов, суммарное заявленное расширение 1 MB, до 200000 байт на элемент и отношение 100:1. Защита рассчитана на локальные доверенные процессы, не на публичный трафик. Отдельной OAuth-реализации, защиты от всех DoS, OS sandbox и security-аудита зависимостей нет. Не отправляйте реальные секреты, конфиденциальные документы и персональные данные. Идентификаторы могут возвращаться в результатах. Журнал содержит только специально подготовленные синтетические входы; сервер не пишет журналы payload.

Все 23 схемы имеют readOnlyHint=true, destructiveHint=false, openWorldHint=false, idempotentHint=true. Это описание поведения, а не разрешение платформы. Метрики и результаты предоставленных тестов не удостоверяют их происхождение; хеш не подтверждает истинность содержания. L3-local означает фактическое обнаружение на отдельном локальном серверном процессе stdio/HTTP, без утверждения о полной MCP SDK совместимости. L4–L6 не подтверждены.
