# Отчёт безопасности (локальная квалификация, не независимый внешний аудит)

Результат: PARTIAL, публичное развёртывание HOLD. Тесты выполнены на CPython 3.13.5 с синтетическими RSA/JWT и собственным временным CA только на 127.0.0.1. Клиент проверял TLS цепочку и имя (без отключения verify); TLS 1.2/1.3. Не подтверждён TLS публичного домена.

Проверены: строгие Host/Origin/scheme, протокол и ID, malformed JSON, дублирующиеся ключи, невалидный UTF-8, surrogate, глубина, NaN/Infinity, превышение 128 KiB, отказ от неизвестного session ID, допустимые Content-Type/Accept, JSON-RPC notification 202, GET 405, ограничения параллельности, rate limit и timeout чтения, отключение/повторное подключение. Доказательства в `SECURE_HTTP_EVIDENCE.json` и `TESTS_030.xml` (часть лимитов проверена непосредственно через ASGI).

JWT: проверка RS256, pinned RSA verification key и kid, тип access token, подпись, exact issuer/audience/owner/client, единственный scope `lab:read`, `iat/exp/nbf`, TTL ≤15 мин, отклонение поддельных, просроченных, чужих, unsigned, malformed, duplicate claims, noncanonical base64url и deep JSON. Никакого JWKS fetch из токена или удалённого исполнения пользовательского кода. 401/403 с metadata challenge. Отдельный issuer не создан, OAuth consent/code/redirect/refresh/revocation и реальные identities не проверены. Нет токен-хранилища и автоматического key rotation. Короткий TTL ограничивает срок отозванного токена, но немедленный revocation не реализован.

Ядро не делает сетевых запросов, не выполняет анализируемые исходники, не извлекает архивы на диск. ZIP ограничен размером, количеством записей, заявленным expanded size, степенью сжатия, типами entries и path traversal; это не полный malware scan и не формальная гарантия защиты от всех повреждённых форматов. `code_structure_analyze` использует AST, не исполняет вход. В baseline suite 269 проверок включены проверки side effects, ZIP и входных схем; они повторены.

Логи: приложение не логирует тело, Authorization, пользовательские данные; test log содержит только синтетические входы и ответы, JWT не записывались. TLS private key и signing key сгенерированы в временной тестовой папке, не входят в пакет. Для удалённой среды отдельно проверить логи reverse proxy/host и retention. No external API, no GitHub write, no D1/KV, no trading operations. Ни одно разрешение существующих плагинов не изменено.

## Обнаруженный блокер зависимостей

- PyJWT 2.13.0 имеет опубликованные GHSA/CVE, включая algorithm confusion, неканонические подписи, обработку JWKS и deep headers. Приложение дополнительно ограничивает RS256, тип ключа, заголовок, кодировку и глубину; это не повод игнорировать advisory. См. GHSA-w2cx-738m-mc7w, GHSA-8wjv-2p76-3863, GHSA-hxm8-2xgr-2p9m; исправления начиная с 2.14.0 по опубликованным карточкам. Выбран pin 2.15.1.
- Cryptography 46.0.4 затронута опубликованными advisory, в частности PYSEC-2026-36; OpenSSL wheel также требует актуальной проверки (GHSA-537c-gmf6-5ccf). Выбран pin 50.0.2. Установленная 46.0.4 не допускается к public deployment.
- Установка целевых версий не удалась. `production_preflight.py` реально отказал запуску с двумя несовпадениями. Известные уязвимые версии оставлены только в протоколе воспроизводимости локальной синтетической проверки. Не считать обновление установленным.
- Автоматический pip-audit отсутствует, пакетный источник недоступен; полный текущий аудит не завершён. Пины не являются обещанием отсутствия уязвимостей. Целевые версии и их совместимость не испытаны. Необходимо обновить зависимости, повторить все тесты, проверить актуальные advisory, полный dependency graph, TLS runtime и внешний OAuth. Docker image не построен.

## Незакрытые security gates

Публичный TLS, удалённый OAuth, официальный SDK, внешнее нагрузочное испытание, лимиты CPU/RAM на хосте, public edge-защита, защита slow headers, ротация/revocation, независимый аудит. 180 requests/min и 4 parallel — глобальные лимиты одного процесса, не per-IP; возможна общая блокировка при атаке. Per-call hard CPU timeout отсутствует, вход ограничен; cgroup limits заданы в Compose, не проверены.
